Bakery Shop Management System 

Project Description 
In many small and medium-sized bakeries, daily operations such as managing perishable 
inventory, handling customer orders, and recording transactions are still conducted manually. This 
traditional approach often leads to human errors—such as selling expired items—delayed billing, 
data loss, and significant inefficiency in monitoring the stock levels of raw materials. The absence 
of an integrated system makes it difficult for owners to track staff performance, product 
availability, and total revenue in real-time. To address these challenges, the Bakery Shop 
Management System is proposed as a comprehensive desktop application developed in C#. This 
system aims to automate the core functions of bakery operations through a secure and user-friendly 
interface. It replaces manual system with a robust, database-driven solution that streamlines the 
entire workflow from production to the final point of sale. The system supports three primary 
roles—Admin, Inventory Manager, and Sales Cashier—each equipped with dedicated interfaces 
for managing staff, products, and sales transactions. By maintaining a centralized database, the 
application ensures data accuracy, prevents redundancy, and provides systematic control over all 
records. Furthermore, it ensures high levels of data integrity through rigorous input validation and 
verification protocols. Ultimately, this solution enhances operational efficiency, reduces manual 
workload, and provides real-time visibility into business performance, allowing for more informed 
decision-making. 

Feature List 
User_1 (Admin) 
1. Login: Secure authentication for system access. 
2. Logout: Securely exit the session. 
3. Registration: Ability to register new user accounts for Admin, Managers and Cashiers. 
4. Show Password: Toggle visibility for secure password entry. 
5. Forget Password: A recovery mechanism that verifies the username against the database 
and retrieves the existing password if a match is found. 
6. View Admin Information: Access and view the logged-in Admin's personal profile details. 
7. Insert Employee: Add new staff records into the database. 
8. Update Employee: Modify staff information. 
9. Delete Employee: Remove inactive or resigned staff. 
10. Search Employee: Find staff records. 
11. Manage Category: Add, update, or delete product categories (e.g., Cakes, Breads). 
12. View Sales Report: Real-time summary of total sales. 
13. Account Status Control: Enable/Disable user access (Deactivate account) for security 
purposes.

User_2 (Inventory Manager) 
1. Log In: Secure authentication for the Manager to log into the system using their username 
and password. 
2. View Personal Profile: Allows the logged-in Manager to view and check their own profile 
details. 
3. Employee Monitoring: Permits the Manager to view and monitor cashier employee 
records. 
4. Add New Products: Allows inserting new bakery items into the database with details like 
price and stock levels. 
5. Update Product: Allows modifying existing product data, including updating prices, 
names, or item descriptions. 
6. Delete Products: Provides the option to remove items from the active product list if they 
are discontinued or out of stock. 
7. Product Search System: A quick search feature to find specific items in the inventory easily 
using names or filters. 
8. Inventory & Stock Control: Tracks and updates available stock levels in real-time to 
maintain a proper supply of ingredients or items. 
9. View Sales Reports: Allows the Manager to view sales summaries and total revenue 
generated to check business performance. 
10. Log out: Securely exit the system and terminate the active session.

User_3 (Sales Cashier) 
1. Secure login and logout system: Access the sales terminal securely and close the session 
post-shift. 
2. View Personal Profile: Access and view the logged-in Cashier's profile details. 
3. Add Products to Cart: Select and add multiple bakery items to a virtual shopping cart based 
on the customer's order. 
4. Modify Cart: Adjust item quantities or remove products from the cart before final 
processing. 
5. Process Orders: Confirm and finalize the transaction once the customer completes the 
purchase. 
6. Automatic Bill Calculation: Automatically compute the total amount, including item rates, 
subtotals, and applicable taxes or discounts, eliminating manual calculation errors.
